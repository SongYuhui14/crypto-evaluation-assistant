# 密评检测检查清单

> 本清单是**工作框架**，用于现场检测时逐项对照、记录证据。
> 测评项编号、判定标准与权重一律以现行 **GB/T 39786-2021、GM/T 0115-2021、GM/T 0116-2021**
> 官方文本为准；现场以实测证据为准，禁止凭印象填写。

判定符号：✅ 符合 ｜ ◐ 部分符合 ｜ ❌ 不符合 ｜ ➖ 不适用

## 常用取证方式（判定时至少取一种证据）

- **文档查阅**：管理制度、密钥管理规程、产品认证证书、设计文档
- **配置核查**：加密套件 / 协议配置、密钥存储位置、口令策略
- **访谈**：管理员对轮换、应急流程的实际执行情况
- **工具检测**：抓包分析 TLS 套件、探测算法、配置基线比对
- **验证测试**：确认加密有效性（数据确实密文存储 / 传输）

## 一、物理和环境安全层面

| 检查点 | 取证方式 | 记录证据 | 判定 |
|---|---|---|---|
| 物理访问控制是否采用密码技术（门禁卡、身份鉴别） | 配置核查 + 访谈 | | |
| 门禁记录 / 进出记录的完整性是否受密码保护 | 文档查阅 + 验证 | | |
| 视频监控记录的真实性、完整性是否受密码保护 | 验证测试 | | |
| 机房环境监测（温湿度、烟感等）记录的完整性保护 | 文档查阅 | | |

## 二、网络和通信安全层面

| 检查点 | 取证方式 | 记录证据 | 判定 |
|---|---|---|---|
| 通信双方身份鉴别是否采用密码技术 | 配置核查 | | |
| 传输信道数据机密性保护（加密协议、密码套件） | 工具检测（抓包） | | |
| 传输信道数据完整性保护 | 配置核查 | | |
| 是否使用国密算法套件（如 SM2/SM4 的 TLS 套件） | 工具检测（抓包） | | |
| VPN / 安全网关等设备的密码产品认证情况 | 文档查阅 | | |

## 三、设备和计算安全层面

| 检查点 | 取证方式 | 记录证据 | 判定 |
|---|---|---|---|
| 设备 / 系统登录身份鉴别是否采用密码技术 | 配置核查 | | |
| 远程管理通道的机密性、完整性保护 | 配置核查 + 抓包 | | |
| 设备固件 / 系统启动的完整性验证（如信任链） | 文档查阅 | | |
| 日志记录的真实性、完整性保护 | 验证测试 | | |
| 设备自身密码模块的合规性（是否取得认证） | 文档查阅 | | |

## 四、应用和数据安全层面

| 检查点 | 取证方式 | 记录证据 | 判定 |
|---|---|---|---|
| 用户身份鉴别是否采用密码技术（双因子、数字证书等） | 配置核查 + 验证 | | |
| 访问控制决策依据的鉴别信息是否受密码保护 | 配置核查 | | |
| 重要数据存储的机密性保护 | 验证测试（抽查密文） | | |
| 重要数据存储的完整性保护 | 验证测试 | | |
| 重要数据传输的机密性、完整性保护 | 抓包 + 验证 | | |
| 关键操作的不可否认性（签名、电子签章） | 文档查阅 + 验证 | | |

## 五、密钥管理

| 检查点 | 取证方式 | 记录证据 | 判定 |
|---|---|---|---|
| 密钥生成：是否使用合规的随机源与算法 | 文档查阅 + 访谈 | | |
| 密钥分发 / 传输：是否加密、是否走安全通道 | 文档查阅 + 访谈 | | |
| 密钥存储：是否加密存储、是否与数据分离 | 配置核查（关键！） | | |
| 密钥使用：用途是否分离（加密/签名/认证各用各钥） | 配置核查 | | |
| 密钥更新：是否有轮换周期并实际执行 | 文档查阅 + 访谈 | | |
| 密钥归档与备份：是否受保护 | 配置核查 | | |
| 密钥销毁：是否按规定销毁并有记录 | 文档查阅 | | |
| 是否存在硬编码密钥、默认口令 | 代码 / 配置扫描 | | |
